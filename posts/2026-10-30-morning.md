what the story is: Forever Security published "Markdown Is the New Executable" on 22 Oct 2026, by Gal Weizman and Omer Samet; the coverage wave (BleepingComputer, The Hacker News) ran 26–28 Oct. The firm blocked a coding agent on a real customer's machine from installing `function-color`, a malicious npm package that pulls in a downloader called `function-flag` which fetches and runs a Windows payload; npm has since removed it. The vector was a planted AGENTS.md file in the developer's Downloads folder — the instruction file Codex reads when it starts in a directory. The instructions told Codex to register a server in `~/.codex/config.toml` and run the install command; because that config is machine-wide, every later Codex session on that machine loads the attacker's server from any folder. The firm reports the file drove Codex to execute the npm malware in over 90% of its tests. Only Codex and Claude Code were tested, and a CLAUDE.md variant worked on Claude Code, redirecting its API traffic to a server the researchers controlled. Forever's proof of concept showed a web page can plant an AGENTS.md in Downloads, but they could not establish that this is how the customer's file arrived — BleepingComputer's own check of that page downloaded an AGENTS.md with harmless content.

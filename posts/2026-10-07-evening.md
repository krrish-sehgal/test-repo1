```

https://horizon3.ai/attack-research/disclosures/anthropic-mythos-rejetto-hfs-rce/
https://www.securityweek.com/exploitation-hits-rejetto-hfs-vulnerability-discovered-by-ai/amp/
```

the story: Horizon3.ai researcher Zach Hanley used Anthropic's Mythos model to find CVE-2026-61500 in Rejetto HTTP File Server, a session-forgery-to-RCE chain carrying a CVSS 4.0 score of 9.3. Two bugs compose: HFS derives the signing key for its session cookies from JavaScript's non-cryptographic `Math.random()`, which is passed to Koa and used by keygrip to sign all session cookies; and HFS leaks outputs of that same PRNG to unauthenticated clients during its Secure Remote Password login handshake. Twelve started logins yield enough output to reconstruct the key, forge an admin cookie and execute code on the host. HFS 3.0.0 through 3.2.0 are vulnerable, 3.2.1 is fixed. Horizon3 published 2 Oct; VulnCheck's Canary Intelligence recorded the first real attacks on 3 Oct against US and Japanese servers from China-hosted addresses. **A number deliberately left out of the post:** VulnCheck counted only about 100 internet-facing HFS instances, so this is a fast-weaponisation story rather than a mass-exploitation one, and putting "about a hundred servers" in the post would have invited readers to round the whole thing down to nothing. One outlet puts the first exploitation at 1 Oct rather than 3 Oct, which appears to describe scanning rather than attacks; the post uses 3 Oct, the date on which five independent outlets agree. Only @AnthropicAI is tagged — @Horizon3ai looks right but was not independently verified to the standard the skill asks for, and Rejetto has no handle I could confirm. **Note on an earlier run:** Mythos has been named in passing in the 09-10, 09-12 and 09-26 logs, but this vulnerability has never been posted; it is a new story, not a follow-up.
sources checked: horizon3.ai (primary disclosure), SecurityWeek, BleepingComputer, eSecurityPlanet, Tech Times (5 Oct), Cyberpress, WindowsForum, secnews.gr, news4hackers, dev.to/techaiwire, dev.to/kielltampubolon (the twelve-request write-up), Expert In the Cloud, Delana Technologies (4 Oct AI-bug-bounty roundup), prsol.cc, hendryadrian.com.

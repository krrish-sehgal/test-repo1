what the story is: on Wed 21 Oct 2026 a malicious build of litellm 1.107.0 was published to PyPI and Docker Hub. litellm is a widely used gateway library that sits between a company's apps and the LLM providers they call. The git tag and GitHub source were clean; the payload existed only in the built wheels (all seven) and in the `v1.107.0`, `latest`, `main-latest` and `main-stable` container images. The wheels installed `cook.pth`, `cook.py` and `sitecustomize.py` into site-packages, which execute on the start of *any* Python process on the host, including processes that never import litellm. The stealer targeted SSH keys, cloud credentials, CI/CD secrets, AI tool tokens, browser passwords and the LLM provider keys held in a LiteLLM proxy database, exfiltrating to a lookalike domain (reported as litellm.dev against the real litellm.ai), and also installed an hourly remote code loader. PyPI removed the release around 13:23 UTC on 21 Oct; container images came down between roughly 11:46 and 14:20 UTC depending on the source. Last known-good version is 1.106.2 per most sources. The closing beat is the best-verified part of the entry vector: LiteLLM says three engineers' GitHub accounts were used via stolen GitHub CLI OAuth tokens, with one account altering the release pipeline and triggering the run, a second approving it, and a third deleting the workflow records. Deliberately kept out of the post: LiteLLM's suspicion that the tokens leaked through logs of an internet-exposed internal deployment, and its claim that Claude Code may have placed GitHub CLI tokens into response bodies — the company itself labels both unconfirmed, and they come only from LiteLLM. Also left out: Chainguard's line that this is the second LiteLLM compromise in seven months (true and single-sourced in my results, but it competes with the ending).
sources checked: The Hacker News (the most directly sourced), Datadog Security Labs, Socket, Wiz, Chainguard, Mend, StepSecurity, Endor Labs, SafeDep, OX Security (diverges — names 1.106.0 rather than 1.106.2 as the last safe version, so the version number is not in the post), Brandefense, Rescana, SOCRadar, CryptoTimes.
